# Global E-Commerce Sales Analysis

##  Project Overview

This project analyzes global e-commerce sales data to understand sales performance, profitability, product categories, customer segments, regions, and other business factors.

The project uses SQL for data analysis and Microsoft Excel for data cleaning, analysis, and dashboard visualization.

##  Project Objectives

* Analyze overall sales and profit performance
* Identify the best-performing product categories
* Compare sales across regions and countries
* Analyze customer segments
* Analyze products and sales performance
* Understand shipping and payment methods
* Generate useful business insights
* Build an Excel dashboard to present the findings

##  Dataset

The project uses a global e-commerce sales dataset containing information about orders, customers, products, sales, profit, regions, product categories, shipping methods, payment methods, and other business attributes.

##  Data Cleaning

The dataset was checked and prepared before analysis.

The cleaning process included:

* Checking for duplicate records
* Checking for missing values
* Checking date formatting
* Checking numerical fields
* Checking sales and profit values
* Checking consistency of categories and regions

##  SQL Analysis

SQL was used to explore and analyze the dataset.

The SQL work is divided into four files:

1. 01_data-analysis.sql
2. 02_data_cleaning.sql
3. 03_sales_anlaysis.sql
4. 04_bussiness_insight.sql

These files contain data exploration, cleaning checks, sales analysis, and business insights.

##  Excel Analysis

The Excel workbook contains four main sheets:

* Raw Data — Original dataset
* Data Cleaning — Prepared and checked data
* Analysis — Business analysis tables
* Dashboard — Visual representation of the findings

##  Dashboard

The Excel dashboard presents important e-commerce metrics and comparisons using:

* KPI cards
* Charts
* Slicers/filters
* Sales analysis
* Profit analysis
* Regional analysis
* Product/category analysis

##  Key Business Areas Analyzed

* Region
* Country

* Payment Method
* Shipping
